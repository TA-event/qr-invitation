# QR Wedding Invitation — Prototype

Static invitation demo prepared for GitHub Pages.

## Included now
- Responsive invitation page
- Animated gold rings with glow
- Rotating orbital accents
- Floral / ornamental decorative details
- Twinkling gold particles
- Reduced-motion accessibility support

## Important: AR model status
The 3D model file `assets/gold-rings.glb` has **not** been created or included yet. The current invitation animation works without it. The AR viewer is a placeholder until a valid GLB model is added at that exact path.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `qr-wedding-invitation`).
2. Upload `index.html`, `README.md`, and the `assets` folder from this project.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the published HTTPS URL shown on the Pages settings screen.
7. Open that URL on a phone to test the invitation. Generate a QR code pointing to the published URL only after it is live.
